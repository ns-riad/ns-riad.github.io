# ns-riad.github.io

Personal academic website of **Md Nazmus Shakib**, a Ph.D. student in ECE at the University of Alabama in Huntsville.

Live at <https://ns-riad.github.io>. Built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) v1 theme.

See **[SITE_GUIDE.md](SITE_GUIDE.md)** for where everything lives and how to update it.

```bash
bundle install && bundle exec jekyll serve   # http://localhost:4000
```
